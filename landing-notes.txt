1. Apa keuntungan memisahkan header dan footer menjadi file component tersendiri, dibandingkan menuliskannya langsung berulang-ulang di index.php?
Memisahkan header dan footer menjadi komponen tersendiri memberikan keuntungan utama berupa kemudahan pemeliharaan kode, karena perubahan menu atau logo cukup dilakukan pada satu file tanpa harus mengedit setiap halaman satu per satu. Pendekatan ini menerapkan prinsip Don't Repeat Yourself (DRY) untuk mencegah duplikasi kode, menjaga konsistensi tampilan di seluruh situs, serta membuat struktur file utama seperti index.php menjadi jauh lebih rapi karena berfokus pada konten spesifik. Selain itu, proses pengembangan halaman baru menjadi lebih efisien karena komponen umum tinggal diimpor menggunakan perintah include atau require.

•	Perhatikan halaman-halaman admin (Buku, Kategori, Penulis, Pengguna, Profil) pada Bagian 2 - bagian mana pada halaman-halaman tersebut yang mengalami masalah yang sama seperti header/footer sebelum dipisah?
Pada halaman-halaman admin seperti Buku, Kategori, Penulis, Pengguna, dan Profil, bagian yang mengalami masalah duplikasi serupa adalah elemen sidebar atau navigasi samping, topbar atau navigasi atas yang berisi informasi akun dan tombol logout, serta pemanggilan pustaka luar seperti file CSS dan JavaScript di bagian <head> maupun sebelum penutup tag </body>. Tanpa pemisahan komponen, penambahan menu baru atau pembaruan pustaka CSS/JS akan memaksa pengembang mengedit kodenya secara manual di setiap file halaman admin tersebut.
